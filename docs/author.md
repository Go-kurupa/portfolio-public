# Go — 養鶏場の仕事を、記録から経営までつなぐ

養鶏場を経営しながら、日々の仕事で使うアプリを、独学でClaude Codeと一緒に作っています。
卵の数を記録するところから、餌量の計算、人と仕事の予定、出荷・在庫、経営の確認まで、現場の困りごとを道具にしてきました。

→ **[アプリ全体のポートフォリオ](https://github.com/Go-kurupa/portfolio-public)**

## 作って使っているもの

| 場面 | アプリ |
|---|---|
| 日々の記録 | 集卵数カウント、死亡羽数管理 |
| 作業の準備と管理 | 餌量計算、シフト管理、業務リスト |
| 届ける・確かめる | 出荷管理アプリ、経営ダッシュボード |
| 周辺の仕事と学び | 領収書保管、Discordボット群 |

- [領収書保管](https://github.com/Go-kurupa/receipt-vault-public)：ClaudeやChatGPTから検索・整理できる領収書庫。訂正は下書きの確認から進め、元の記録を残します。

個人用のOCR試作もありますが、ソースと実装の詳細は非公開で、今回のソース提出対象には含めていません。

## 開発で大事にしていること

現場の使い方と、間違うと困る条件を言葉にし、設計・実装・テスト・実機確認を繰り返しています。
AIが作ったコードの動作を実行結果で確かめ、実際に使って分かった問題を次の変更へ戻します。

開発の中心はClaude Codeで、2026年10月からはCodexにも実装・調査・レビューの一部を任せています。
第三者の技術と、自分が追加した機能の範囲を区別し、業務データと開発履歴の公開範囲を慎重に扱っています。

[具体例と検証の記録を見る](https://github.com/Go-kurupa/portfolio-public)
