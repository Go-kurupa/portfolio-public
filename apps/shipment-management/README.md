# 出荷管理

注文を出荷予定へまとめ、実際の出荷と委託先の在庫を確認する、養鶏場向けの業務アプリです。
販路によって異なる注文・納品の扱いを、一つの画面で管理するために作っています。

## 主な機能

- 単発・定期購入・ギフト・卸など、販路ごとの受注と出荷予定を管理する
- 予定を実際の出荷記録へ確定し、数量や取引先を確認する
- 委託先への納品・販売・期限切れ・手動補正から、残っている在庫を計算する
- 保存済みの在庫状態から計算を再開し、全期間を再計算する場合との一致をテストする

## 使う流れ

1. 注文や定期購入の条件に応じた出荷予定を確認します。
2. 出荷する数量を確認し、実際の出荷記録へ確定します。
3. 委託分は納品・販売などの記録から在庫を確認します。
