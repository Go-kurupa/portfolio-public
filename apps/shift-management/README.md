# シフト管理アプリ

勤務希望を集め、管理者が調整したシフトを月ごとに公開するための業務アプリです。
働く人の希望と、現場を回すための勤務予定を分けて扱います。

## 誰が、何に使うか

- 勤務する人は、自分の勤務希望を登録します。
- 管理者は、集まった希望を確認し、勤務予定を調整します。
- 調整したシフトを月ごとに公開し、勤務予定を確認できるようにします。

## 主な機能

| 機能 | 扱うこと |
|---|---|
| 勤務希望の登録 | 働く人が希望する勤務予定を記録する |
| 管理者による調整 | 希望を確認し、勤務予定を組み立てる |
| 月次の公開 | 調整した月のシフトを公開する |
| 予定の確認 | 公開されたシフトで勤務予定を確認する |

## 使う流れ

1. 勤務する人が、対象月の勤務希望を登録します。
2. 管理者が希望を確認し、シフトを調整します。
3. 管理者が月のシフトを公開します。
4. 公開された勤務予定を確認します。
