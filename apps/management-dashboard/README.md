# 経営ダッシュボード

養鶏場の生産と経営の数字を確認する業務アプリです。
日々の現場の記録と、売上・入金・支出を見ながら、月の記録を確定する判断につなげます。

## 主な機能

- 生産性・収益・支出の画面で、目的に応じて数字を確認する
- 集卵・餌・死亡などの現場の記録を、経営の確認につなげる
- 売上と会計側の入金を、金額と日付の条件で対応付ける
- 月の記録を確定する操作について、実行できる人を判定する

## 使う流れ

1. 生産性の画面で、現場の記録と推移を確認します。
2. 収益・支出の画面で、売上や費用を確認します。
3. 売上と入金の対応を確かめ、権限のある利用者が月の記録を確定します。

各データの取込みには別の処理や設定が関わります。画面を起動するだけで全データが自動連携するという意味ではありません。
