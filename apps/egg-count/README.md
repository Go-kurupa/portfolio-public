# 集卵数カウントアプリ

養鶏場で集めた卵の数を、日付と鶏舎ごとに記録するアプリです。
卵のサイズ、集卵した場所、集卵回を分けて入力し、同じ日の死亡羽数も記録します。

## 何を記録するか

| 記録の単位 | 内容 |
| --- | --- |
| 日付・鶏舎 | いつ、どの鶏舎で集めた卵か |
| 集卵した場所 | 巣内・巣外 |
| 集卵回 | 1回目・2回目 |
| サイズ・区分 | S・MS・M・L・2L・割・廃棄の個数 |
| 死亡羽数 | 同じ日・鶏舎の雄と雌の死亡数 |

鶏舎の設定には、飼育開始日、開始時の日齢、初期羽数を保持する項目もあります。
記録のデータ構造は `types.ts` に定義しています。

## 使用例

ある日の集卵後に、対象の日付と鶏舎を選びます。
巣内で1回目に集めた卵をサイズ別に入力し、巣外で集めた卵や2回目の集卵も区分して記録します。
死亡があった場合は、その日の雄・雌の死亡羽数を入力します。

このように、日ごとの合計だけでなく「どの鶏舎の、どの集卵区分か」を残します。
例は操作の流れを説明するもので、実際の鶏舎名や業務データは掲載していません。
