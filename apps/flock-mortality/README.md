# 鶏死亡羽数管理アプリ

養鶏場の部屋ごとに、雄・雌それぞれの死亡羽数を日別に記録するアプリです。
開始時の羽数や日齢とあわせて、飼育中の記録を管理します。

## 何を記録するか

| 記録の単位 | 内容 |
| --- | --- |
| 部屋 | 記録対象の部屋の名前 |
| 開始時の情報 | 開始日、開始時の日齢、雄・雌の初期羽数 |
| 日別の死亡数 | 日付ごとの雄・雌の死亡羽数 |
| メモ | その日の記録に添える補足 |

部屋のデータには、搬出期間と搬出後の雄・雌の羽数を保持する項目もあります。
データ構造は `src/types.ts` の `RoomData` に定義しています。

## 使用例

飼育を始めるときに、部屋の開始日、開始時の日齢、雄・雌の初期羽数を設定します。
その後は日付を指定して、雄と雌の死亡羽数をそれぞれ記録します。
補足がある日はメモを添えます。

日々の死亡数と開始時の情報を、同じ部屋の記録として扱います。
例は記録の流れを説明するもので、実際の部屋名や飼育データは掲載していません。
