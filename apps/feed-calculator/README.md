# 餌量計算アプリ

鶏舎の部屋ごとに朝の残餌を記録し、前日から引き継いだ給餌量をもとに、その日の給餌量を確認するアプリです。現場での給餌判断と日々の記録を支えます。

## できること

- 鶏舎・部屋ごとに、朝に確認した残餌の状態を入力します。
- 前日からの持越給餌量に、残餌判定に応じた増減量を加え、設定した上下限内で自動給餌量を計算します。
- 新しい部屋や空舎明けには、開始時の基準給餌重量を設定できます。
- 給餌量の刻み・上下限などの調整設定を管理します。
- 必要な日は合計給餌量を手動で上書きできます。手動値が設定範囲を外れる場合も、自動計算値とは区別して扱います。
- 給餌の推移をグラフで確認し、配合レシピや飼料原価の情報を管理します。

持越量は「前日から引き継いだ給餌量」です。食べ残した餌そのものの重量とは区別しています。

## 使用の流れ

1. 設定画面で鶏舎・部屋と開始給餌量、増減の刻みや上下限を確認します。
2. 対象日と鶏舎を開き、部屋ごとに朝の残餌を入力します。
3. 計算された給餌量を確認し、現場の判断で必要な場合は手動値を入力します。
4. 日々の給餌記録やグラフで推移を確認します。
