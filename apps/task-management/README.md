# 業務リストアプリ

日々の仕事をタスクとしてまとめ、担当者や完了日、チェックリストを確認するための業務アプリです。
作業の名前だけでなく、誰が担当し、どこまで進んだかを記録として扱います。

## 主な機能

| 機能 | 扱うこと |
|---|---|
| タスクの管理 | 行う仕事をタスクとして記録する |
| 担当者の記録 | 誰が担当する仕事かを確認する |
| 完了日の記録 | 作業を完了した日を記録として残す |
| チェックリスト | タスクに含まれる作業項目を確認する |

## 使う流れ

1. 行う仕事をタスクとして登録します。
2. 担当者やチェックリストを確認して作業します。
3. 作業の完了と完了日を記録し、タスクの状況を見返します。
